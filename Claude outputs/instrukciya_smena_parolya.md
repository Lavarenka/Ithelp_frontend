# Что нужно сделать: смена пароля на странице профиля

Код уже полностью написан и проверен (и на бэкенде, и на фронтенде). От тебя нужно только два шага — ничего писать не надо, только перезапустить сервер и проверить в браузере.

## 1. Перезапусти backend (FastAPI)

Это единственный обязательный шаг. Новый эндпоинт `PATCH /auth/me/password` появится в приложении только после перезапуска процесса — Python (в отличие от Vite на фронте) не подхватывает изменения в коде на лету, если сервер запущен без флага автоперезагрузки.

- Если backend запущен в терминале (например `python -m uvicorn app.main:app` или `uvicorn app.main:app --reload`) — просто останови его (`Ctrl+C`) и запусти заново той же командой.
- Если запущен с флагом `--reload` — он мог и сам перезапуститься при сохранении файлов, но лучше перепроверь по логу в терминале, что не было ошибок при старте.
- Если backend запущен через Docker (`docker-compose.yml` в проекте есть) — перезапусти контейнер: `docker-compose restart` (или `up -d --build`, если контейнер собирается из образа, а не монтирует код).

Frontend (Vite) трогать не нужно — там всё подхватится само.

## 2. Проверь в браузере

Открой сайт → зайди в свой профиль (иконка пользователя в шапке → Профиль / Profile).

Внизу под разделом "Имя пользователя" теперь два варианта:

- **Если у тебя обычный аккаунт (логин+пароль)** — увидишь блок "Пароль" с тремя полями: "Текущий пароль", "Новый пароль", "Повторите новый пароль" и кнопку "Сохранить".
- **Если ты зарегистрирован(а) только через Google/GitHub** — увидишь блок "Установить пароль" всего с двумя полями (без "текущего пароля") и подсказкой, что можно задать пароль, чтобы дополнительно входить по логину/паролю. Кнопка будет называться "Установить".

Что стоит проверить руками:

1. Ввести неправильный текущий пароль → должна появиться ошибка "Текущий пароль указан неверно".
2. Ввести разные значения в "Новый пароль" и "Повторите новый пароль" → должна появиться ошибка "Пароли не совпадают".
3. Ввести всё правильно → появится зелёное сообщение "Пароль успешно обновлён" (или "Пароль установлен" — для тех, кто задаёт пароль впервые).
4. Разлогиниться и зайти уже с новым паролем — убедиться, что старый больше не работает, а новый работает.

## Важный нюанс про базу данных

Никаких миграций базы делать не нужно — колонка `hashed_password` в таблице `users` уже существовала раньше (у пользователей, вошедших только через Google/GitHub, она просто хранится как пустая строка). Новый код просто научился её проверять и обновлять через новый эндпоинт, структура базы не менялась.

## Если после перезапуска что-то не работает

Пришли скриншот ошибки (из браузера — консоль/сеть, или из терминала backend) — разберёмся сразу.
